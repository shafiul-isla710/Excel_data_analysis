# Excel Sales Data Analysis Project Completed!

In this project, I practiced:
✅ Nested IF – Categorized sales performance as Excellent, Good, or Average.
✅ VLOOKUP – Retrieved target revenue by region and calculated the difference between actual and target revenue.
✅ SUMIF – Calculated total revenue for each region and identified the highest-performing region.
✅ COUNTIFS – Counted sales that met specific conditions.
✅ Pivot Table & Slicer – Summarized revenue and units sold by region and product, with interactive filtering.

Through this project, I improved my Excel skills and learned how to analyze sales data to support better business decisions.
